ReaL Redacter 是一款面向 Windows 10 和 Windows 11 的离线可逆文档脱敏工具。

当前版本为 `2.2.2`，支持 x64 Windows，采用便携版运行方式，不需要安装程序，也不需要联网。

## 主要功能

- 完全在本机处理文档，不上传文件，不调用云端 API
- 支持 Word、Markdown 和 TXT 文档
- 支持单文件脱敏和文件夹批量脱敏
- 支持金额、数字、百分比规则
- 支持自定义敏感词，例如填写 `苹果` 后，文档中的所有“苹果”都会被脱敏
- 使用 Token 和映射文件实现可逆恢复
- 支持恢复为 Word、Markdown 和 TXT
- 尽量保留 Word 的标题、段落、表格、粗体和斜体等基础格式
- 支持拖入文件或文件夹
- 支持深色和浅色界面

## 下载

本仓库为私有仓库，只有被邀请的协作者可以访问。

下载 Windows 版本时，请打开 GitHub 的 `Actions` 页面，进入 `Build Windows x64`，打开最近一次成功的运行记录，在页面底部的 `Artifacts` 区域下载：

`ReaL-Redacter-2.2.2-windows-x64`

GitHub Actions 构建产物默认保留 14 天，请及时下载并在本地备份。

## 运行方法

1. 将下载的 ZIP 文件完整解压到 Windows 电脑。
2. 打开解压后的 `ReaL Redacter` 文件夹。
3. 双击 `ReaL Redacter.exe` 启动程序。

请不要直接在压缩包内部运行，也不要单独移动 `ReaL Redacter.exe`。程序需要和 `_internal` 文件夹放在一起。

首次启动时，Windows 可能显示 SmartScreen 提示。这是因为当前版本没有进行微软代码签名。确认文件来源可靠后，可以点击“更多信息”，再选择“仍要运行”。

## 单文件脱敏

1. 在左侧选择“脱敏”。
2. 选择一个 `.docx`、`.md` 或 `.txt` 文件，也可以直接拖入文件。
3. 在“脱敏规则”中勾选需要启用的规则。
4. 如需脱敏指定内容，在“自定义脱敏内容”中每行填写一个词。
5. 选择输出格式和输出目录。
6. 点击“开始脱敏”。

处理完成后，程序会生成一个以“脱敏文件”结尾的文件夹，其中包含脱敏文档和对应的还原映射文件。

例如：

```text
报告.docx
报告 脱敏文件/
├── 报告已脱敏.docx
└── 报告还原映射文件.json
```

## 批量脱敏

1. 在“脱敏”页面选择一个文件夹，或直接拖入文件夹。
2. 设置脱敏规则和输出格式。
3. 在“设置”中选择批量处理并发数量。默认值为 `1`，更稳定，文件很多时可以选择 `2`、`4` 或 `8`。
4. 点击“开始脱敏”。

程序会递归处理文件夹内支持的文档，并保留原有的子目录结构。单个文件失败不会影响其他文件，处理结果和错误报告会保存在批量脱敏文件夹中。

## 恢复文档

恢复时必须同时准备：

- 已脱敏的文档或审核文件
- 与它对应的还原映射文件 `.json`

操作步骤如下：

1. 在左侧选择“恢复”。
2. 选择已脱敏文档或 HTML 审核文件。
3. 选择对应的还原映射文件。
4. 选择输出格式。
5. 点击“恢复并导出”。

恢复依赖文档中仍保留的 Token 标记和对应的映射记录。HTML 审核文件会保留 Token ID 关联。普通文字的修改、增加或删除不会影响仍然存在的 Token。已经删除的脱敏标记不会被恢复，仍保留的标记会恢复为原始内容。

恢复结果会保存在以“恢复文件”结尾的文件夹中。

## 映射文件注意事项

还原映射文件是恢复原文所必需的文件，请和脱敏文档分开备份。

映射文件只在本机生成和使用，文件内包含本地保护信息和 MD5 完整性校验。请不要手动修改其内容，也不要把不同文档的映射文件混用。

如果映射文件丢失、损坏，或者脱敏文档中的 Token 被完全删除，对应内容将无法恢复。

## 常见问题

### 程序打不开

请确认已经完整解压，并且 `ReaL Redacter.exe` 与 `_internal` 文件夹位于同一个 `ReaL Redacter` 文件夹中。

### 点击后一直没有反应

请检查输入文件是否真实存在、格式是否为 `.docx`、`.md` 或 `.txt`，并确认输出目录具有写入权限。

### 部分内容没有被脱敏

请检查对应规则是否已经勾选。对于固定名称、项目代号或其他指定内容，可以在自定义脱敏区域中每行填写一个敏感词。

### 恢复失败

请确认选择的是同一份脱敏文档对应的映射文件，并确认文档中的 Token 标记没有被全部删除。

### Word 格式发生变化

当前版本会尽量保留标题、段落、表格和基础文字样式。复杂页眉页脚、文本框、特殊字体、宏和复杂排版可能无法完全保持一致。

## 隐私说明

ReaL Redacter 面向本地单用户使用。文档、映射文件、配置和日志都保存在本机，不依赖账号、云服务或外部 API。
